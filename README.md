# Flag Game

An Android game for learning flags, and the capitals that go with them.

## Flag sets

- **Countries**: all 197 (UN members plus Kosovo, Palestine, Taiwan and Vatican City), by continent.
- **Territories**: 38 dependent territories with a flag of their own (Greenland, Puerto Rico, Hong Kong, ...).
- **US states**: all 50, by census region.
- **Belgium**: the 10 provinces plus the Brussels-Capital Region, and the flags of 34 cities.

## Quizzes and game modes

Choose **Flags** (name the place) or **Capitals** (name its capital; every set except the Belgian cities has them). Then pick a mode:

1. **Multiple choice**: four options, wrong ones from the same region where possible.
2. **Type the answer**: type it, or tap the microphone and say it. Case, accents and small typos (including swapped letters) are forgiven, but naming a different real place (Zambia for Gambia) is not. Names are accepted in English, the phone's language and many translations; Belgian places in English, Dutch and French.
3. **Find it on the map**: tap the place (or, for capitals, the city) on a zoomable map. Small places are shown as dots. A miss shows where you tapped and where the answer is.
4. **Colour the flag** (flags only): paint the flag from a 9-colour palette. Pinch or use the +/- buttons to zoom in. Flags with very detailed emblems are left out.

Every mode can be limited to one region (or to Belgian provinces or cities) and to 10, 20 or all questions. Best scores are saved on the device.

## Building

Needs JDK 17+ and the Android SDK (platform 35).

```
./gradlew assembleDebug     # app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest
```

GitHub Actions builds a release APK on every push to `main` (see the workflow's artifacts).

## Game data

`app/src/main/assets/<set>/` holds each set's names (`items.json`), map (`map.json`), flags and colouring templates. They are generated by `tools/build_assets.py`; see the docstring at its top for the source layout. In short:

```
npm pack flag-icons world-atlas world-countries region-flags us-atlas   # extract each to <src>/<name>/package
pip install cairosvg pillow numpy geonamescache
python3 tools/fetch_belgium.py <src>/belgium          # Belgian flags (Wikimedia Commons) and provinces (Eurostat GISCO)
python3 tools/build_assets.py <src> /tmp/x --us-capitals > capitals.json
node tools/project_us.mjs < capitals.json > <src>/points.json   # npm i d3-geo
python3 tools/build_assets.py <src> app/src/main/assets
```
