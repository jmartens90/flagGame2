# Flag Game

An Android game for learning the flags of all 197 countries (UN members plus Kosovo, Palestine, Taiwan and Vatican City).

## Game modes

1. **Multiple choice**: pick the right country out of four. Wrong options come from the same region where possible.
2. **Type the answer**: type the country's name, or tap the microphone and say it. Case, accents and small typos are forgiven, but naming a different real country (Zambia for Gambia) is not. Answers are accepted in English, the phone's language and the 20+ translations in the country data.
3. **Find it on the map**: tap the country on a zoomable world map. Very small countries are shown as dots. A miss shows where you tapped and where the country is.
4. **Colour the flag**: paint the flag from a 9-colour palette. 178 flags without complex emblems are included in this mode.

Every mode can be limited to a region (Africa, Americas, Asia, Europe, Oceania) and to 10, 20 or all flags. Best scores are saved on the device.

## Building

Needs JDK 17+ and the Android SDK (platform 35).

```
./gradlew assembleDebug     # app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest
```

GitHub Actions builds a release APK on every push to `main` (see the workflow's artifacts).

## Game data

The files in `app/src/main/assets` are generated by `tools/build_assets.py` from npm packages:

```
npm pack flag-icons world-atlas world-countries   # then extract each to <src>/<name>/package
pip install cairosvg pillow numpy
python3 tools/build_assets.py <src> app/src/main/assets
```
